更新：2026-10-30（Asia/Tokyo）。ブリーフ指定の10作品はユーザー判断によりα版採用済みです。ここには技術上の制限と未試験範囲を記録し、芸術的な採用判断を再度求めません。

| 項目 | 現状／次の確認 |
|---|---|
| 履歴試験中の単発console例外 | `MutationObserver.observe` のNode引数例外を1件観測。発生元URL・スタックなし。009で同じ履歴／リロード操作を3往復して再現せず、描画・復帰の失敗もなし。原因を特定できていないため、次の実機試験で発生条件とスタックを採取する。元HTMLを推測で修正していない |
| 実機タッチ・他ブラウザ | 390px幅・Pointer Eventsの長押し／ドラッグ／クリックは確認済み。iOS／Android実機、Safari／Firefox、マルチタッチは未検証。まず実機で全館を一巡する |
| 既存作品内の操作 | 館内はタッチ歩行可能。作品内は既存操作を保持し、全作品に新しい自由歩行パッドを追加したわけではない。003等の操作パネルの占有、009／010の縦長表示・内部スクロールなどは既存の制約。造形を変えず外側UIの改善対象を体験後に決める |
| Reduced motion・支援技術 | 館内は地図優先、Autoは明示開始。既存作品内部のアニメーションを一括停止していない。スクリーンリーダー／OS設定の実機試験は未実施 |
| GPU・長時間負荷 | 館内はDPR最大1.5、鑑賞時は館内RAFを停止、退出時にiframeを破棄。GPUメモリ回収量・長時間連続入退場・低性能端末でのFPSは未測定 |
| 作品の外部依存 | 館内Three.jsはMIT固定版をローカル同梱。既存作品のCDNは原本どおり。通信断／CDN障害時は読み込み説明と固定復帰導線を用意したが、全作品の通信断を注入した試験は未実施 |
| WebGL非対応端末 | 館内の失敗時にも全10作品への一覧導線は残る。WebGLを必要とする作品自体が非対応端末で描画できることまでは保証しない |

| 公開 | mainマージ、本番公開、CRITTトップへの本番リンク追加は実施していない。今回のPRはasset-integrationに対する独立したレビュー用差分 |
