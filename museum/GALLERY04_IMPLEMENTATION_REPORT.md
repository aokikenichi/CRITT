# 統合回遊実装／工程04 — 実装報告

実施日：2026-10-30（Asia/Tokyo）

## 完成物

`museum/gallery.html` に、入口ホール、中央通路、各2作品を持つ5展示室を連続した3D空間として実装しました。ブリーフ指定の全10作品へ入場し、固定の「展示室に戻る」から入場前の座標・向きへ戻れます。

基点は `codex/museum-asset-integration` / `5f47308a76201cd550c81302666ec6500b5bb296`。作業ブランチは `codex/museum-walkthrough-alpha`、新規PRのbaseも `codex/museum-asset-integration` です。main、PR #1／#2、本番導線、公開設定は変更しません。

今回のユーザー指示を採用判断の根拠として、指定10作品は**α版採用済み**として接続しました。旧比較記録の「作者採用未承認」は当時の記録として保全し、再審査を着手条件にしていません。正式原画の登録とは別であり、全 `originals[]` は引き続き0点です。

## 空間と操作

- 入口から伸びる中央通路に第1〜4室が左右交互に接続し、奥に第5室があります。床・壁・開口部・天井・採光・展示フレーム・サインを同一シーンに配置しました。
- 第1室「静止と時間」、第2室「線と所有」、第3室「身体と群衆」、第4室「記憶と軌跡」、第5室「重力と境界」。大きさ、天井高、採光面、素材色が異なります。
- WASD／矢印で前後左右へ歩き、ドラッグで見回します。速度は2／3.5／6 m/s。細分化した移動と壁の矩形衝突判定により、長いフレームでも壁を飛び越しません。
- モバイル幅／coarse pointerでは移動パッドと旋回ボタンを表示。Pointer Eventsによる押し続け操作、ドラッグ見回し、タップ鑑賞に対応します。
- 展示に近づくと番号・題名と鑑賞ボタンを表示し、E／Enterまたはクリック／タップで入場します。プレビューは既存QA画像を参照し「作品プレビュー／制作中」と表示します。原画に登録していません。002のプレビューには002の人物表示を含む記録を使います。
- 館内Autoは入口から5室の10地点を連続歩行し、各地点で3.5秒停止して作品名を表示します。一時停止・再開・Manual切替が可能です。作品を自動起動せず、作品内Autoにも干渉しません。
- 館内図・部屋ショートカット・全作品一覧を用意しました。WebGL失敗時は一覧を開き、`prefers-reduced-motion`では地図から開始します。歩行／Autoは利用者が明示的に選びます。キーボード、native dialog、フォーカス復元に対応します。

## 鑑賞と復帰の境界

外側のnative dialogに固定復帰ボタンと同一オリジンの共通鑑賞iframeを配置し、既存シェル内の作品iframeを継承します。開くURLは新しい固定台帳だけから選び、queryやhashから任意URLを渡しません。`postMessage`は使用しません。

入場時に座標x/z・yaw/pitchを保存し、館内入力を消去、館内requestAnimationFrameを停止します。閉じると作品iframeをabout:blankに遷移させて除去し、その子の描画環境を破棄します。ブラウザのGPUメモリ回収タイミング自体は保証しません。館内座標を復元し、歩行画面にフォーカスを返します。

History APIは入場前の姿勢を履歴stateに保存します。戻る・進む・鑑賞中リロードに対応し、直打ち `#work=010` は入口を復帰先として開きます。不正hashは除去します。Escは館内鑑賞ビューを閉じず、作品内のモーダル操作を優先します。

既存作品HTML・シェルファイルは変更せず、外側の新規JSがiframe実行時だけ共通UIをコンパクト化します。比較版の切替・前後作品ナビは統合ビューでは非表示にし、番号と起動版の対応を維持します。鑑賞情報にはα版採用済みと過去記録の区別を添えます。作品の造形・画像・重力・ガイド経路には触れていません。

## ファイルと依存

- `gallery.html`、`css/gallery.css`：統合入口、館内図、鑑賞ビュー、レスポンシブUI。
- `js/gallery-model.mjs`：固定10作品、5室、壁、経路、衝突・保存座標の検査。
- `js/gallery-scene.js`：建築、照明、プレビューの3D描画。
- `js/gallery.js`：入力、Auto、鑑賞ライフサイクル、履歴、地図、失敗時表示。
- `vendor/three-0.180.0/`：既存作品にも使われるThree.js固定版をMITライセンスと共に同梱。館内自体のCDN依存を除きました。既存作品のCDN依存は保全。
- `tests/gallery-model.test.mjs`、`tests/gallery-environment.html`：経路／保護資産検査と環境失敗のQA専用fixture。
- `GALLERY04_BRIEF.md`：受領ブリーフ。`GALLERY04_QA.md`、`GALLERY04_PENDING.md`、`qa-results/gallery04/`：結果と証跡。

実行：リポジトリのルートで `python3 museum/tests/serve.py --port 8000`、入口は `http://127.0.0.1:8000/CRITT/museum/gallery.html`。静的HTMLでありビルド・新規バックエンド・解析タグ・送信サービスはありません。
