# 10作品連続回遊 α版 — 実装記録

2026-11-01 / branch `codex/museum-ten-exhibits-v2` / 基準 `TEN_EXHIBIT_CONTRACT.md` v2.0。

新入口は [exhibition.html](exhibition.html)。入口から5展示室（各2作品）、出口まで、1つのThree.jsシーン・カメラ・座標系・歩行処理で接続する。iframe、作品HTMLの起動、展示用スクリーンショットは使っていない。旧 `index.html`、`gallery.html`、`gallery-direct-pilot.html` は変更していない。

## 起動

リポジトリルートで `python3 museum/tests/serve.py --port 8756` を実行し、`http://127.0.0.1:8756/museum/exhibition.html` を開く。`/CRITT/museum/exhibition.html` にも対応する。GitHub Pagesへの公開やmainへのマージは行わない。

ManualはWASD／矢印・ドラッグ、Q/E・R/Fで視線。タッチ用の移動／視線ボタンも共通配置する。Autoは選択作品の3視点を実際に歩く。館内案内の館内Autoは001〜010の30視点と出口を巡る。各視点には固有の解説と6秒の鑑賞時間があり、歩行速度は1・2・4倍。Pause/Resume、次の見どころ、手動入力による中断に対応する。

解説・画像・設定は共通dialogへ集約し、開くとAutoをPause。閉じた時に視点を維持し、起点のボタンへフォーカスを戻す。画像は選択、1〜4倍拡大、スクロール、全体表示、来歴・SHA-256表示がある。

## 原本と移植

最初に原本対応表と `verify-ten-exhibit-sources.py` で10/10を照合した。原本のhash/bytesは変えていない。`tests/extract-ten-exhibit-assets.py` は元HTMLを読んで88個の埋め込み画像（同一画像を含む）を実バイトで抽出し、`exhibition-assets/manifest.json` に原本blob、行、SHA-256、bytes、区分を記録する。

原画として正式承認されたことを示す情報はないため、画像ビューアでは「制作参考画像（正式原画としては未確認）」と表示する。007の画像は元ソースでも架空の史料風創作素材。010には埋め込み画像がないため「未収録」と原本の来歴を表示する。新しい作品画像は生成していない。

各 `exhibits/001`〜`010` は `mount/enter/update/leave/dispose` と `highlights/details/images/controls` を持つ。アダプタのローカル座標に共通カメラを逆変換して作品固有の反応を計算する。隣接室まで表示し、遠い室は描画を抑える。室間の移動でページやカメラを切り替えない。

共通当たり判定は館内の壁・開口、001の球、004/005の画像作品の基部を扱う。浮遊物、光、横断が主題の010の境界は歩行を遮らない。Autoも同じ歩行領域を経路探索し、壁を通り抜けない。元HTMLの閉じた壁・元の入力／描画ループは移植せず、作品の描画を共有空間へ取り込んでいる。

Three.js r180は既存のローカル同梱版を使用。JSZip 3.10.1も元008と同じ版を同梱し、新入口は外部CDNに依存しない。JSONとZIPはブラウザ内で処理し、送信しない。
