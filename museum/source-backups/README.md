# 工程③ 入力資料の保存

`INPUT/` は受領ZIPからシェル実装前にコピーした原本です。元の暫定台帳・棚卸し・計画書・資産マニフェストを記録として維持しています。`CODEX_TASK_STEP03.md` も受領時の内容です。

- `works/009/index.html`、`works/010/index.html` は対応する原本HTMLとバイト単位で同一です。描画・作品内部の入力ロジックは変更していません。
- `CANDIDATE_NOT_ORIGINAL/` の3枚は未承認の候補素材です。正式採用原画として登録していません。
- 元マニフェストに記載されていても、このZIPにない旧版・スクリーンショットを取得済みとは扱いません。
- 旧版との視覚的な比較はできません。受領資料の履歴を、今回検証した実体や操作と区別します。
- 共通シェル内で行う表示ラベルとフォーカスの補正は `../js/museum-shell.js` および実装報告に記録しています。

検査：リポジトリルートで `python3 museum/tests/validate-assets.py`（Python 3.9以降）。
