# ドットボールの連鎖

## 対象

2026年11月23日に取得したCricsheetの男子T20I公式JSON（v1.3.0）を使用した。配布ZIPの**3,649試合、109チーム、820,257記録投球**を対象とした。試合日は2005年2月17日〜2026年11月1日。合法球は784,761球で、スーパーオーバー70イニングの401投球は対象外とした。配布元は別途166試合を非提供としている。収録されていない大会・対戦カードもあるため、集計上の「世界」はCricsheetの公開分を指す。

日本の打撃記録は2022年10月10日〜2026年9月22日。2026年9月26日の対ネパール戦はネパール側に投球記録があり、日本側に打撃記録がなかった。全チームの収録数・打撃試合数はページの「チーム別の収録試合数」と[集計JSON](../../data/dot-ball-pressure.json)に掲載した。

## 観測結果

1. **次球もドットになる割合は、連鎖が長いほど高かった。** 0球では37.34%（204,019 / 546,429）、5球以上では51.05%（3,815 / 7,473）。差は+13.71ポイント（試合単位の95%区間 +12.39〜+15.04）。同じ条件でバウンダリーの割合は13.95%（76,202 / 546,429）と11.28%（843 / 7,473）だった。2球以内に得点した割合は81.69%（446,073 / 546,042）と70.37%（5,256 / 7,469）だった。
2. **世界全体の生のアウト率は5.5〜5.9%に収まった。** 0球の5.68%（31,032 / 546,429）に対し、5球以上は5.85%（437 / 7,473）。差は+0.17ポイント（95%区間 −0.36〜+0.69）。長い連鎖の後にアウトが増えるという全体傾向は、この比較からは確認できない。調整後の結果も下記に示す。
3. **次球のドット率と連鎖の関係は、PowerplayよりDeathで大きかった。** 0球から5球以上への差はPowerplayで+6.07ポイント（74,499 / 159,744 と 2,172 / 4,121）、Deathで+19.01ポイント（39,154 / 128,161 と 284 / 573）。差の差は+12.94ポイント（95%区間 +8.61〜+17.28）。アウト率はMiddleで4.84%（12,501 / 258,524）から6.44%（179 / 2,779）へ上がったが、PowerplayとMiddleの差の差の95%区間は−0.16〜+2.16ポイント、DeathとPowerplayは−3.13〜+1.81ポイントだった。局面間でアウトとの関係が異なるという証拠は限られる。
4. **日本の短い連鎖は比較できる球数があり、5球以上は参考値にとどまる。** 直前に1球以上の連鎖があった割合は日本31.72%（2,130 / 6,716）、日本の打撃を除く世界33.40%（271,698 / 813,541）。連鎖後の次球得点率は日本58.92%（1,255 / 2,130）、同世界57.76%（156,937 / 271,698）、差は+1.16ポイント（95%区間 −1.64〜+3.96）。脱出率の差は+2.06ポイント（1,699 / 2,130 と 211,022 / 271,561、95%区間 −0.46〜+4.57）。アウト率の差は−0.34ポイント（116 / 2,130 と 15,707 / 271,698、95%区間 −1.20〜+0.53）。日本の5球以上は20試合38投球で次球アウト0件（95%区間 0.0〜21.0%）、Deathに限ると2試合3投球だった。

## 交絡要因を調整したアウトの分析

アウトの有無を目的変数とする二項ロジスティック回帰を820,257投球、46,855アウト投球、3,649試合に当てはめた。連鎖長、打撃チーム、守備チーム、局面、投球前の失ウィケット数、年代（2005〜2014、2015〜2019、2020〜2023、2024年以降）をすべてカテゴリとして投入した。区間は試合単位クラスタのサンドイッチ分散（CR1）で計算した。

| --- | ---: | ---: |
| 0 | 1.000 | 基準 |
| 1 | 1.051 | 1.026〜1.076 |
| 2 | 1.059 | 1.020〜1.100 |
| 3 | 1.029 | 0.972〜1.089 |
| 4 | 0.987 | 0.902〜1.081 |
| 5以上 | 1.002 | 0.910〜1.104 |

1〜2球はモデル上で約5〜6%高いオッズを示した。3球以上の各区間は1を含み、連鎖が長いほどアウトのオッズが高まる単調なパターンは見られなかった。チーム項は平均的なチーム差を取り込む。時点ごとの対戦相手の強さ、打者・投手の力量、会場、目標点と必要得点率などは残存交絡の候補である。局面との交互作用はこの回帰に含めず、上の局面別比較は未調整。割合・オッズ比とも観測された関係であり、連鎖の因果効果を識別できない。区間は各比較についての95%区間で、多重比較の補正は行っていない。

## 集計定義と検証

- 投球順は各イニングのオーバー・投球の記録順。直前の合法かつチーム0点の投球を数え、オーバーをまたいで連鎖を維持する。ワイド・ノーボールは結果の「次球」に含め、以後の連鎖を途切れさせる。
- 合法のチーム0点球は退場やアウトを伴ってもドットと数える。その球の後の連鎖は0に戻す。負傷などによる非アウト退場（`retired hurt`、`retired not out`）はアウト件数に加えない。退場アウト（`retired out`）、ランアウトなどは含める。同球に複数イベントがあってもアウト率の分子は1投球。
- チーム得点は `runs.total`。内訳を検証し、投球に付いた追加点を含める。イニング開始・終了時に一括付与されたペナルティ点は個別の投球には割り付けない。打者4点か6点で `non_boundary` が偽・未指定の投球をバウンダリーとする。
- 脱出率は当球で得点、または当球が連鎖を継続するドットで次球が得点した割合。無得点の退場・アウトで連鎖が終わった後の得点は脱出に含めない。判定不能は、継続するドットでイニングの記録が終わった524投球。比較は結果となる当球の局面で区分する。
- 局面はオーバー番号に固定。Powerplayは1〜6、Middleは7〜15、Deathは16〜20。短縮試合が含まれ、実際の守備制限期間や終盤とずれる場合がある。T20国際試合の11件で `info.overs` が50だった。通常イニングがいずれも20オーバー以内の記録なので、分類には各投球の実際のオーバー番号を使用した。
- 個別割合には試合別の残差分散から求めた有効標本数を使うWilson型の近似95%区間を付けた。0件または全件では試合サイズからKishの有効試合数を使い、2試合未満は区間なし。差には同一試合から出る各割合の寄与を合成したデルタ法の95%区間を用いた。100投球または20試合に満たない条件は参考値。試合のクラスタ化は、同一選手が複数試合に出る影響や収録の偏りまでは補正しない。
- 自動テストで、手計算のアウト率1 / 2と得点率2 / 2、オーバー・イニングの境界、非合法球、得点とアウトの同時発生、脱出の分母を確認した。公式ZIPを逆向きに走査する別計算でも、世界・日本を除く世界・109チームの各局面・連鎖長1,998条件について、全主要指標の件数が一致した。調整モデルの係数とクラスタ区間は手計算できる小規模データでも照合した。
