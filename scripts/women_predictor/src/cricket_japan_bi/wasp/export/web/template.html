ABOUT WASP

WASPとは？

WASP（Win And Score Predictor）は、クリケットの試合中に「第1イニングの最終得点は何点になりそうか」「第2イニングで追走側が勝つ確率はどのくらいか」を、現在の得点・wicket・残り球などの試合状況から推定する考え方です。

WASPと同じ発想のリアルタイム予測は、その後、Play-CricketのWASP機能やCricVizのWinViz／PredictVizなど、放送・デジタル配信・商用分析サービスにも展開されています。

このツールは公式WASPのアルゴリズムをそのまま再現したものではありません。WASPが扱った「最終得点予測」と「勝率予測」という問題設定を参考にし、Cricsheetのball-by-ballデータと現代的な機械学習を使って独自に推定しています。

HOW TO USE

使い方

先攻予測

第1イニング途中の得点・wicket・消化overを入力すると、最終得点の予測値と50%／80%予測区間を表示します。

追走予測

第2イニングのtarget・現在得点・wicket・残り球を入力すると、追走成功確率を表示します。トス結果が分かる場合は選択するとチーム情報モデルを利用できます。

リプレイ

収録済みの試合を選ぶと、実際の試合進行に沿って最終得点予測と追走成功確率の推移を一球ごとに確認できます。

見方のポイント

数値は公式値ではなくモデル推定です。試合序盤ほど不確実性が大きく、終盤になるほど予測は安定します。

注記

得点と確率は事実・公式値ではなく、収録試合に基づく推定です。
強い国・弱い国との対戦では、相手の実力差を考慮した追加補正が必要です。現在は検証に十分な日本女子代表戦のデータがないため、日本代表向けの追加補正は適用していません。

      予測モデル

      第1イニング：Histogram Gradient Boosting回帰を中心とした候補モデル比較により、現在の試合状態から残り得点を推定します。予測最終得点 = 現在得点 + 予測残り得点として算出し、50%・80%予測区間を表示します。

      第2イニング：Histogram Gradient Boosting分類およびロジスティック回帰等を比較し、現在得点、wicket、残り球、target、必要run rate等から追走成功確率を推定します。

      チーム情報：Elo、batting form、bowling suppression、venue等の試合前情報を候補モデルで利用します。

      世界の女子T20 Internationalデータで学習したモデルを日本女子代表戦にも適用します。

      本ツールは公式WASPのアルゴリズムを再現したものではなく、WASPと同じ『第1イニング最終得点／第2イニング追走成功確率』という問題設定をCricsheetデータと独自の機械学習モデルで実装したWASP-style分析です。
