## 保存・運用方針

- 元の `museum/recovered/sources/001〜010/` および `museum/works/009〜010/` は**変更・削除しません**。
- 本集約は所在の一本化であって、既存の技術評価や芸術的な完成判定を変更するものではありません。
- 001・002の再制作と全館2.5Dの統合は別工程です。002は特別な技術方式ではなく全10作品とも2.5Dを基本とします。
- 過去に002の3D人体メッシュを不採用とし、既存ソースの figureMode A の2.5D人物レイヤーを基準とする指示がありました。
- 003〜010は**実在する既存成果物**です。原本を探し直したり再生成したりしないでください。
- 採用ファイルの出所・原本SHA・サイズは [MANIFEST.json](MANIFEST.json) に記録しています。
- 既存の実装契約は [TEN_EXHIBIT_CONTRACT.md](../TEN_EXHIBIT_CONTRACT.md)、採用元台帳は [TEN_EXHIBIT_SOURCE_MAP.json](../TEN_EXHIBIT_SOURCE_MAP.json) を参照してください。
- HTMLの実行には既存版のWebGLや外部CDN等への依存が残る場合があります。10件の集約をもって全館の直接回遊が完成したとはみなしません。
