## 3. 10作品共通の鑑賞フォーマット（最優先）

### 3.1 共通上部・下部UI

- 左上：**CRITT Museum / BEYOND THE BOUNDARY**、現在の展示室、作品番号・作品名。
- 右上：**原画を見る**／**作品について**／**操作方法**／**音のON/OFF**（音がない作品では非表示）／**UIを隠す**。
- 下部：**前の作品｜作品一覧｜次の作品**。Manual/Autoは対応作品で同一位置・同一名称。「自由鑑賞」「ガイド鑑賞」を併記。
- 初回だけ簡単な操作案内。戻る・閉じる動作、Esc対応、モバイルのタップ領域を統一。
- 作品IDは `001`〜`010` とし、`010` のように3桁表記に統一。

### 3.2 「原画を見る」は全作品に共通実装

- 選ぶと**鑑賞HTMLではなく、制作者が採用した高解像度の原画（画像自体）**をオーバーレイ表示。
- 拡大／縮小／100%／画面に合わせる／元の鑑賞へ戻る。スマホはピンチズームが使える設計。
- 複数原画なら「代表原画・別視点・連作の各場面」を同じビューア内で切替可能。
- 表示する画像を `artworks.json` で明示し、**HTMLのスクリーンショットを原画の代わりにしない**。元の原画が見つからない場合は「原画未登録」とし、捏造した画像に置き換えない。
- 原画のキャプションに「CRITTの架空作品／生成画像」「制作年」「権利表記」を表示。外部の実在作品と混ぜない。

### 3.3 共通の「作品について」

必須項目：番号・作品名／短い鑑賞文（50〜120字）／問い（1文）／素材・表示方法／操作方法／作品の試作状況／架空・生成表現の明示。文献との関係は「史実」「研究者・作家の解釈」「CRITT独自の発想」を区別。

### 3.4 統一**しない**もの

各作品の原画、空間の広さ、光と音、作品自体の操作、2D・2.5D・3Dの手法、静寂／参加型などの演出。共通の額縁に素材を差し替える方式は採用しない。

## 4. 技術統合方針（Codex）

### α版は既存作品を壊さない「共通シェル方式」を推奨

- 外側に `museum/index.html`（入口）、`museum/work.html?id=001`（共通ナビ／原画／解説）、`museum/works/001/index.html` ... `010/index.html`（現状の個別HTML）を用意。
- 作品HTMLは可能な限り**現状のまま保存**し、iframe等の隔離または薄いアダプター経由で展示。各作品を一括でThree.js等に書き換えない。
- 共通シェルが作品台帳を読み込み、タイトル・原画・解説を表示。Manual/Auto切替は作品側が対応している場合にのみ連携し、内部機能が未実装の作品には存在しないボタンを付けない。
- `postMessage` 利用時は送信元チェックと限定したメッセージ種別を実装。端末の戻る操作・履歴に対応。
- 音声や動く背景はユーザーの操作と設定を尊重。`prefers-reduced-motion`、字幕、2D代替、キーボード操作を整備。
- GitHub Pagesで相対パスを統一。特に `/CRITT/` 配下への設置を想定。リンク切れ・ファイル大小文字を検証。

例：

```
museum/
  index.html                # 入館ページ
  work.html                 # 作品共通シェル
  artworks.json             # 全作品メタデータ
  references.html           # 実在美術館・関連展覧会
  about.html                # 展覧会趣旨・クレジット
  assets/originals/001/...  # 原画（各作品分）
  works/001/index.html      # 作品固有の鑑賞体験
  ...
  works/010/index.html
  css/museum.css
  js/museum-shell.js
```

台帳の最低限の項目：`id`, `title_ja`, `room_id`, `question`, `statement`, `work_url`, `originals[]`, `technique`, `credits`, `rights_status`, `alpha_notes`, `manual_supported`, `auto_supported`。 `originals[]` には画像URL・altテキスト・画像の役割・由来を記載。

4. **Farihah Aliyah Shah, _Are You Not Entertained?_（2026）** — クリケット、植民地史、サトウキビと個人史を結ぶインスタレーション。作家公式：https://www.farihahshah.com/are-you-not-entertained

## 7. α公開の合格条件

1. **001〜010に必ず到達できる**（作品ナビで番号の欠落やループがない）。
2. 共通の「原画を見る」が10作品にあり、登録されたオリジナル画像にアクセスできる。登録漏れは公開前に解消する。元画像が取得できない場合は**未達**と記録し、勝手に画像を代替しない。
3. 作品本体のManual／Auto／閲覧機能を破損せず、共通ラベルとの整合を確認。未実装機能は「未対応」と明示する。
4. 主要なPC・スマホの閲覧で作品が見えなくなる等の重大欠陥がない。重い3Dが使えない端末に2D鑑賞導線がある。
5. 各作品に作品名・見どころ・架空作品／生成画像の区別・クレジット・出典表記がある。
6. 先行事例ページの外部リンクが有効。実在博物館と実在展の違いが明瞭。
7. CRITTトップから入館し、展覧会からCRITTトップへ戻れる。
8. 「α版／実験公開」「未完成箇所」「実在の美術館・団体と無関係」を明示。
